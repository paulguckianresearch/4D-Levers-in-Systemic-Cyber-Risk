# 4D-Levers-in-Systemic-Cyber-Risk
Code and outputs for "Levers in Systemic Cyber Risk: Which Matter, and When": Morris and Sobol sensitivity analysis of a frozen simulated estate model (doi:10.5281/zenodo.23669511), response-surface validation on 60,000 fresh configurations, a timing revision, a mechanism-validation package, and the run outputs the paper cites.
